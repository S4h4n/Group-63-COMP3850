MAC Setup
Open Terminal in IDE editor and ensure you're in the codebase directory

Step 1:
brew install --cask miniconda

Step 2:
conda init zsh

source ~/.zshrc


Step 3:
conda create -n snn-env python=3.10 -y

conda activate snn-env

If using Silicon Chip:
pip install tensorflow-macos==2.13.1
pip install tensorflow-metal

Step 4:
pip install ipykernel jupyterlab ipywidgets

pip install -r requirements.txt

Test codebase

Step 4:
Run all the modules, simply hit run on all the sections

Once you reach Step 5: Evaluation and Visualization. 
- You may need to do the following if has an error
    conda activate snn-env
    pip install matplotlib seaborn
Should work fine now
