SETUP GUIDE

The maintained setup instructions are in README.md, section:
Installation: Windows and Mac.

Use Python 3.10 in a fresh Conda environment and install requirements.txt.
The requirements file automatically selects the platform TensorFlow package.
Use VS Code with the Python and Jupyter extensions.
Do not run the former zsh commands in Windows Anaconda Prompt.
Do not install an unpinned TensorFlow Metal plugin as part of the base setup.
